# Meta.ai

این مخزن شامل مثال‌هایی برای ساخت یک عامل/Expert Advisor (EA) برای انجام معاملات به روش Hedging در MetaTrader 5 است.

محتویات اضافه‌شده توسط Copilot:
- Experts/HedgeEA.mq5 — یک EA ساده به زبان MQL5 (نمونه)
- Agents/hedging_agent.py — عامل پایتون که می‌تواند با MetaTrader5 package وصل شود و معاملات Hedging را اجرا کند
- .env.example — فایل نمونه برای متغیرهای پیکربندی (مقداردهی در فایل .env محلی، هرگز در گیت)
- docs/hedge-systemd.service — نمونه‌ی unit برای اجرای عامل پایتون به‌عنوان سرویس systemd در VPS
- README.md — راهنمای راه‌اندازی و هشدارهای ایمنی (فارسی)

تذکر امنیتی مهم
- هرگز شماره حساب، رمز عبور، توکن یا کلید خصوصی را در این مخزن عمومی قرار ندهید.
- از فایل .env محلی یا متغیر محیطی استفاده کنید و فایل .env را به .gitignore اضافه کنید (قبلاً اضافه نشده — لطفاً اگر لازم است اعلام کنید تا اضافه کنم).
